# AI Investigation Room

An interactive AI Investigation Room built for the **AI Automation Platform Workshop**.

## Features

- Case brief input
- Automated investigation summary
- Evidence extraction
- Persons-of-interest panel
- Investigation timeline
- Recommended next actions
- Responsive mobile-friendly UI
- Runs entirely in the browser with no backend required

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

For a local development server, you can use VS Code Live Server or:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

This project can be deployed using GitHub Pages, Netlify, or Vercel.

### GitHub Pages

1. Create a **public** GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for the deployment.
6. Copy the generated live URL into the workshop submission form.

## Project purpose

The project demonstrates how an investigation workflow can be automated by converting an unstructured case description into structured evidence, persons of interest, a timeline, and recommended next actions.

> Note: This is a workshop demonstration and should not be used as a real-world investigative or law-enforcement decision system.
